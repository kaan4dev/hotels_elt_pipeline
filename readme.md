# Hotels ELT Pipeline

## Overview
This project implements an end-to-end ELT (Extract, Load, Transform) pipeline for hotel reservation data, leveraging big data and modern orchestration technologies. The aim is to efficiently process, transform, and analyze large volumes of hotel booking records for downstream analytics and machine learning.


## Technologies Used
* Apache Spark (PySpark): Scalable distributed data processing for ETL and transformations.
* Apache Airflow: Workflow orchestration and task scheduling (implied by your request; please add your DAGs if available).
* Jupyter Notebook: Interactive data analysis, transformation, and exploration.
* Python: Scripting, data manipulation, and integration.
* Pandas, Matplotlib, Seaborn: Data analysis and visualization within notebooks.
